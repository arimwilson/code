# Wordle Solver API

Dependency-free Rust implementation of the API described in `wordle_rust_api_plan.md`.

## Commands

```bash
cargo test
cargo run --bin wordle-backtest
cargo run --bin wordle-server
python3 scripts/update_wordle_data.py
```

The server listens on `127.0.0.1:7878` by default and serves the web UI at `/`. Override with:

```bash
WORDLE_ADDR=127.0.0.1:9000 cargo run --bin wordle-server
```

For hosted environments, set `PORT`; the server will bind `0.0.0.0:$PORT` when `WORDLE_ADDR` is not set.

## Docker

```bash
docker build -t wordle-solver .
docker run --rm -p 10000:10000 wordle-solver
```

## Endpoints

- `GET /`
- `GET /v1/health`
- `GET /v1/metadata`
- `POST /v1/solve`

Example `POST /v1/solve` body:

```json
{
  "guesses": [
    {
      "word": "slate",
      "statuses": ["absent", "absent", "absent", "absent", "absent"]
    }
  ],
  "mode": "hybrid",
  "hard_mode": false,
  "limit": 10
}
```

## Data

`wordle-data/` is generated by `scripts/update_wordle_data.py`.

Sources:

- `allowed_guesses.txt`: `https://raw.githubusercontent.com/Roy-Orbison/wordle-guesses-answers/main/guesses.txt`, merged with answers and observed historical solutions.
- `candidate_solutions.txt`: `https://raw.githubusercontent.com/Roy-Orbison/wordle-guesses-answers/main/answers.txt`, merged with observed historical solutions.
- `past_solutions.json`: `https://wordle.today/answers`.

As of the latest update in this checkout, `past_solutions.json` contains 1,807 rows through Wordle 1,806 on `2026-05-30`. The source hides the current-day answer until it is published.
